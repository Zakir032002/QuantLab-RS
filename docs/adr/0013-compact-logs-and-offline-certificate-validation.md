# ADR-0013: compact logs and offline certificate validation

Decision: retain the legacy in-memory LogEntry API and v0 decoder, but emit
qlrs-reduce-log/v1 with one record per validated state and final certificate
entry. Removed unit IDs use inclusive sorted RLE. Full/probe counters are captured
at commits; certificate log counters describe proof serialization after its pass.
Rejected speculative candidates do not inflate the wire log.

V1 manifests always serialize certificate_candidates_tested, including zero.
The certificate labels zero as vacuous. Full rechecking validates source-unit
bijections, minimal boundary pins, the direct CSR edge commitment, complete root
coverage, actual rejection reasons and candidate counts. It first validates the
baseline predicate; a false baseline cannot prove minimality by making all
removals fail. Partial certificates are valid integrity artifacts, never proofs
of complete minimality.

Keep v0 behavior and encoding via default/omitted extension fields. An actual
bundle generated by archived source 281fa154 is the compatibility fixture,
with reconstruction commands recorded outside its allowlisted directory.

The saved nonmonotone counterexample adds a zero-contribution illegal lifecycle
to an otherwise admitted cash witness. P(A) is true, P(B) false despite A subset B.
If the full local window is illegal, try the exact seed within budget before
rejecting the input. An immutable illegal contributing suffix remains rejected
by the existing req_reduce_007 test. No monotonicity theorem is assumed.

No fingerprint codec or protected golden changes are needed.
